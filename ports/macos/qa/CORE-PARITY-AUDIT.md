## 硬缺口与优先级

1. **HVF SIMD Q30已修复并进入独立新包。** 固定Google base `f0c183f1...`和10月27日`emu-main-dev` tip `cf0f40a0...`均有`case30→Q20`；[查询证据](/Users/azuki/ModAVD/.macos-work/qa/google-qemu-current-branches-hvf-map-20261101.json)保留检索时间及源码SHA。不泛指所有发行版，更不归因Apple HVF API。[D0006](/Users/azuki/ModAVD/incoming/macos-qemu/0006-hvf-arm64-fix-simd-q30-map.patch)修正后，隔离真实HVF全部32寄存器canonical API/guest STR/LDR与原缺陷负控通过；[完整QEMU SIMD证据](/Users/azuki/ModAVD/incoming/macos-qemu/experimental/evidence/20261101-v5-simd-snapshot-r3/capture.json)又完成10次pause/resume、3次snapshot save/load/delete，2,135,867,594轮无错。只覆盖单CPU忙worker，不涵盖每vCPU、宿主睡眠或游戏；探针主动损坏Q30负控验证探针敏感性，不冒称旧QEMU负控。
2. **生产物理RAM回收仍未对齐。** Manager当前明确写/读回order9；旧v6裸客体实读10，v7四次旧launch仅有4MiB SG而没有逐次sysfs读取，不能反推出其最低order。私有v4/v5已补安全门禁、暂停和回滚；v6连续VA中的独立2MiB对象已有native机制正证。后续私有v7改256KiB对象，Android telemetry-only四个resident事务含同offset两代释放，覆盖三个地址范围/768KiB去重范围；这不是当前净节省。map-fault的271事务全部回滚，9个resident窗口保持旧对象且无释放；1834个尾对象只读诊断全cold。每SG预算不是整个BH上限，metadata净成本及生产收益仍未闭合，故保持私有opt-in。见[v7增量记录](/Users/azuki/ModAVD/ports/macos/qa/hvf-object-reclaim/v7-android-progress.md)；mincore归零、RSS/footprint、累计提交和候选数不单独作为物理释放或净收益证据。
3. **Darwin native bind 结果已补齐观察与传播，完整故障矩阵仍待验收。** 新增 [gfxstream overlay](/Users/azuki/ModAVD/incoming/macos-gfxstream/0001-darwin-verify-native-context-binding.patch) 将 void helper 改为 bool，并核对调用线程的 NSOpenGL 与 CGL current context 是否均匹配目标；解绑要求两者均清空。非空context+nil window返回false，core-profile nil pbuffer仍允许。EGL将结果交给G0014/G0016已有通用失败处理。完整production native源与真实private contexts的27项检查通过，包括无声bind失败仍保留旧current、nil window拒绝、nil pbuffer成功和解绑；增量构建/严格签名也通过，见 [EN报告](/Users/azuki/ModAVD/.macos-work/qa/native-context-bind-fixed-20261101.json) 与 [构建收据](/Users/azuki/ModAVD/.macos-work/qa/core-egl-bind-update-20261101.json)。只证明current-context后置状态可观测，不涵盖所有drawable attachment、context loss/OOM、旧式非nil pbuffer或完整EGL/Android渲染恢复。
4. **原优化条件在 Apple GPU 上不能照搬。** GLSL4.30 fallback 对系统 GL4.1 无保证；WC→cached 虽默认开，Apple shared/device-local 类型通常不满足条件；隐藏 ReBAR 与 ASTC→BC3 没有核心能力门禁，正常 Darwin Manager/runtime 分别关闭或默认关闭。直接启动核心仍可由环境变量开启不适用实验。详见 G0002/G0011/G0012/G0020/G0022；没有 Apple 对照数据时不宣称性能或内存收益。
